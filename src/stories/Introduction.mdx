# Delightful UI

A Svelte 5 library of native controls with caller-owned content and optional green theme styles.

Import components from `delightful-ui` and the optional global theme from `delightful-ui/theme.css`. This preview includes the theme.

Use native attributes and callback events. Inputs support native FormData submission and optional value binding. Dialog triggers and close controls belong to the caller. Translate labels in the application before passing strings or snippets.

See the repository README and `docs/svelte-5-breaking-changes.md` for setup and migration details. This migration has not been released.
